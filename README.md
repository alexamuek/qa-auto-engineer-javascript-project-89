### Hexlet tests and linter status:
[![Actions Status](https://github.com/alexamuek/qa-auto-engineer-javascript-project-89/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/alexamuek/qa-auto-engineer-javascript-project-89/actions)  

Description: this project has the tests of Hexlet Flowbot Widget.   

To install dependencies run ```make install```  
To run tests run ```make test```  
To run linter check run ```make lint```  
To use vitest-preview debug add in test file ```import { debug } from 'vitest-preview'```, add ```debug()``` and before running of tests run ```npx vitest-preview```  
To run web server run ```npm run dev```
